A make.fun "The Dog Reviews the Mailman" entry: a tiny pure-Python program that writes one funny one-line review a dog gives the mailman to /output/entry.txt. One line, under 200 characters, in the dog's own voice — a grievance, a suspicion, and a small triumph over the mailman, with a turn at the end.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
